Privacy Policy

Last Updated: February 16, 2026

✅ Quick Summary

Your privacy is 100% protected. All data stays on YOUR computer. We don't upload anything to the internet, don't share your data with anyone, and don't track what websites you visit.

Introduction

Internet Usage Tracker ("we," "our," or "the app") is committed to protecting your privacy. This Privacy Policy explains how our application handles data and what information practices we follow.

Data Collection

What Data We Collect

Internet Usage Tracker is designed with privacy as a core principle. The app collects and processes the following data locally on your device only:

  1. Network Usage Statistics:
    • Download and upload speeds
    • Total data transferred (bytes)
    • Network interface types (Wi-Fi, Ethernet, Hotspot)
    • Daily and monthly usage totals
  2. Application Settings:
    • User preferences (theme, refresh rate)
    • Data limit configurations
    • Floating window customization settings
  3. Usage History:
    • Historical network usage data
    • Daily usage logs for charts and graphs

What Data We DO NOT Collect

  • ❌ NO personal information (name, email, phone number)
  • ❌ NO browsing history or websites visited
  • ❌ NO application-specific usage data
  • ❌ NO location data
  • ❌ NO device identifiers
  • ❌ NO contact lists or personal files
  • ❌ NO information about what you do online

How Data is Used

All data collected by Internet Usage Tracker is used exclusively for the following purposes:

  1. Display Real-Time Network Statistics: Show current download/upload speeds and calculate total data usage
  2. Track Usage History: Generate usage charts, graphs, and provide daily, weekly, and monthly reports
  3. Data Limit Alerts: Notify you when approaching set data limits and help manage your internet usage
  4. Application Settings: Remember your preferences and restore floating window position

Data Storage

Local Storage Only

All data is stored locally on your device. Specifically:

  • Location: C:\Users\[YourName]\AppData\Roaming\InternetUsageTracker\
  • Files: JSON text files containing usage statistics and settings
  • Access: Only accessible by you and the application

No Cloud Storage

  • ✅ NO data is uploaded to any server
  • ✅ NO cloud synchronization
  • ✅ NO remote backups
  • ✅ NO data transmission to third parties

Data Sharing

We Do Not Share Your Data

Internet Usage Tracker DOES NOT:

  • ❌ Share data with third parties
  • ❌ Sell data to advertisers
  • ❌ Upload data to external servers
  • ❌ Use analytics or tracking services
  • ❌ Integrate with social media platforms
  • ❌ Send telemetry data to developers

Your Data Stays on Your Device. All network monitoring and data processing happens entirely on your local machine. No information ever leaves your device.

User Rights

Your Control Over Data

You have complete control over your data:

  1. View Data: All data is stored in plain JSON files at %AppData%\InternetUsageTracker\
  2. Export Data: Export usage history to CSV format using the "Export to CSV" feature
  3. Delete Data: Use the "Reset All Data" button in settings or manually delete files
  4. Opt-Out: Disable specific tracking features in Settings (Wi-Fi, Ethernet, Hotspot)

Third-Party Services

No Third-Party Integrations

Internet Usage Tracker does NOT use:

  • ❌ Analytics services (Google Analytics, etc.)
  • ❌ Advertising networks
  • ❌ Crash reporting services
  • ❌ Social media integrations
  • ❌ Cloud storage providers
  • ❌ Payment processors (app is free)

Open Source Libraries

The app uses the following open-source libraries locally only:

  • Hardcodet.NotifyIcon.Wpf (v2.0.1) - System tray icon functionality
  • Newtonsoft.Json (v13.0.4) - JSON file reading/writing

Both libraries do not collect any data.
